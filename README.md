# ネイリスト3級 練習帳（2027年冬期対応）

JNEC ネイリスト技能検定試験 3級（2027年1月17日）に向けた、iPhone向けの練習用Webアプリです。

**アプリを開く：** https://nail-kentei-apps.github.io/nail-kentei3/

## できること

- **筆記**：分野別・ランダム・苦手だけ・30分の模擬試験
- **タイム**：実技65分の時間配分を工程ごとに計測して記録
- **持ち物**：試験要項にもとづく持ち物・セッティングのチェックリスト
- **写真**：爪の写真にガイド線を重ねて形をセルフチェック（写真はどこにも送信しません）

## 使い方のメモ

- iPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」でアプリのように使えます
- 記録は使っている端末のブラウザの中に保存されます。ブラウザのデータを消すと記録も消えます
- 筆記問題は出題範囲に合わせたオリジナル問題です。公式の問題ではありません
- 試験の内容はJNEC「2027年冬期 試験要項」をもとにしています。最新の情報は必ず公式要項で確認してください
